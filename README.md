# CryptoTells (Android 10+ / API 29+)

A Material 3 Kotlin + Jetpack Compose app to compare any fiat currency against any cryptocurrency or token using live CoinGecko market data.

## Compatibility
- **Minimum SDK:** Android 10 (API 29)
- **Target SDK:** Android 15 (API 35)

## How to Build the APK in Android Studio
1. Extract `CryptoTells-Android.zip` and open the `CryptoTells-Android` folder in **Android Studio** (Ladybug or newer recommended).
2. Wait for Gradle Sync to finish (it will download Jetpack Compose and Coroutines dependencies automatically).
3. Go to **Build > Build Bundle(s) / APK(s) > Build APK(s)** (or click **Run** to install directly on your Android 10+ phone via USB debugging).
4. Once built, click **locate** in the notification to grab `app-debug.apk`.
